Desarrollar el pseudocodigo del taller 10

Deberá entregar el deber en su repositorio para lo cual se recomienda:

Instalar el git en su computadora.
En una carpeta de trabajo ejecutar el comando:
git pull https://github.com/logicaprogramacion-curso-2026/<<apellido>>-<<nombre>>-unidad3

esto descarga el directorio <<apellido>>-<<nombre>>-unidad3 como un directorio (repositorio)

Crear dentro del repositorio la carpeta deber6-pseudocodigo-taller10

Crear el archivo README.md con las indicaciones que requiera la tarea

Crear los archivos que usted considere conveniente dentro de ese pseudocidogo

Documentar la actividad en un archivo de WORD con la caractula respectiva y el formato de la universidad

Crear un documento en powerpoint para defender su trabajo en donde explique el pseudocódigo que ha desarrollado.

Una vez que tenga todos los archivos que cumplan con su actividad sincronizarlos al repositorio

git add .

git commit -m <<El comentario como se recomendó en las indicaciones>>

git push
En esta actividad del canvas, enviar el link de su repositorio (apuntando a la tarea 6)
